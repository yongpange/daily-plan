# 每日计划

一个本地优先的每日计划、计时与复盘工具。所有任务、工作记录、感悟和复盘数据都保存在项目目录中的 SQLite 文件，不依赖云端账号。

当前版本：0.14.1

## 启动

在 Windows 中双击 `启动每日计划.bat`（自动构建前端并以生产模式启动），或在项目目录运行：

```powershell
pip install -r requirements.txt   # 首次运行
py -3 -m app.main
```

浏览器会自动打开 `http://127.0.0.1:8765`。运行窗口需要保持打开，按 `Ctrl+C` 停止。服务端基于 FastAPI（Python 3.10+），分层结构见 `AGENTS.md`。

前端是 Vue 3 + Vite + TypeScript 工程（`frontend/`）。日常开发先 `py -3 -m app.main --no-browser`（后端 :8765），再 `npm run dev`（前端 :5173，`/api` 代理到 8765）。

## 数据与持久化

首次启动后会在项目内生成：

```text
data/daily_plan.sqlite3
```

它是唯一的权威业务数据，可以直接交给 SQLite、Python、Pandas 或数据库查看工具做后续分析。

- 任务、子任务、计时段、感悟和复盘会立即写入 SQLite。
- 刷新网页、关闭浏览器或重启服务后，业务数据仍然存在。
- `localStorage` 只保留当前日期、当前视图、专注/休息偏好和恢复提示，不保存业务记录。
- 同一时间只允许一条任务计时；启动另一条时会自动结束上一条。
- 备份前请先停止服务，再复制 `data/daily_plan.sqlite3`，避免遗漏 WAL 中尚未合并的数据。

## 主要能力

### 今日计划

- 设置当天最重要的一件事。
- 按项目添加任务，填写预估时间和计划开始时间。
- 将任务继续拆成子任务；父任务作为容器，不重复计入计划总量。
- 当计划超过 8 小时时给出负荷提醒。
- 收工时逐条处理未完成任务：明天继续、改期或放弃，并记录原因和下一次预估。

### 计时与专注

- 普通计时使用开始/结束按钮，自动累计有效工作时间。
- 专注模式支持 25、50、90 分钟预设和 5–180 分钟自定义时长。
- 完整专注到点后自动封账并开始休息倒计时；提前结束仍计入实际工作时间，但不算完整专注段。
- 今日工作日志按时间段保留开始、结束、任务、项目和时长。
- 误操作可以修正时长或删除对应工作记录。

### 感悟与复盘

- 每日长感悟自动保存。
- 碎片感悟支持日期、标签、搜索、置顶、编辑和删除。
- 搜索结果会同时检索碎片感悟和每日感悟。
- 周、月、季度报告统一展示计划与实际、完成率、估时偏差、项目投入、未完成原因、顺延任务、专注统计和有效工作热力图。
- 系统会根据历史数据生成可执行的复盘洞察，每个周期也可以保存自己的文字结论。

这些交互借鉴了成熟效率产品中的意图式日计划、任务拆解、项目计时、专注周期、收工仪式、结构化复盘和碎片记录机制；实现、数据结构和界面均为本项目自身代码。

## 主要数据表

- `projects`：项目
- `tasks`：任务及父子关系
- `plan_entries`：任务在某一天的安排、预估和收工结果
- `time_segments`：普通计时、专注计时及实际工作时间段
- `days`：每日重点、长感悟、状态评分和收工状态
- `memos`：可检索、可置顶的碎片感悟
- `reviews`：周、月、季度文字复盘
